# TestCaptive Test Suite

Playwright (Python) test runner for tests generated by TestCaptive.

## Setup

```bash
pip install -r requirements.txt
playwright install
```

## Usage

1. **Generate tests** using the Chrome extension + VS Code extension
2. **Copy** the generated `.py` file into `tests/`
3. **Copy** the test data JSON as `test_data.json`
4. **Run**:

```bash
pytest tests/ -v

# With browser visible
pytest tests/ -v --headed

# Headless (CI mode)
HEADLESS=true pytest tests/ -v
```

## Structure

```
test-suite-project/
├── conftest.py          # Pytest fixtures (page, test_data)
├── pytest.ini           # Pytest configuration
├── requirements.txt     # Python dependencies
└── tests/
    └── session_<id>/       # One folder per recorded session
        ├── test_recorded.py    # Generated test
        ├── test_data.json      # Test data (editable)
        └── session.json        # Raw session capture
```

Each session folder is self-contained. The `test_data` fixture automatically loads
`test_data.json` from the same folder as the test file.

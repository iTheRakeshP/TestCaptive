# TestCaptive Test Suite

Pre-configured Playwright (Python) test runner for executing tests generated by TestCaptive.

## Setup

```bash
cd playwright-suite
pip install -r requirements.txt
playwright install
```

## Usage

1. **Generate tests** using the Chrome extension + VS Code extension
2. **Copy** the generated `.py` file into `playwright-suite/`
3. **Copy** the test data JSON alongside it
4. **Run**:

```bash
cd playwright-suite
pytest test_generated.py -v

# With browser visible
pytest test_generated.py -v --headed

# With debug output
pytest test_generated.py -v -s
```

## Test Data

Edit `test_data.json` to customize input values:

```json
{
  "input-first-name": "John",
  "input-last-name": "Doe",
  "input-email": "john.doe@example.com",
  "select-country": "United States"
}
```

## Structure

```
playwright-suite/
├── conftest.py          # Pytest fixtures
├── test_data.json       # Test data (customizable)
├── pytest.ini           # Pytest configuration
└── requirements.txt     # Python dependencies
```

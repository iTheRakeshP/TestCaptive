# 🧪 TestCaptive Test Suite Project

A plug-and-play test suite project that automatically utilizes test code generated by TestCaptive's Chrome and VS Code extensions. Uses **Playwright** for test execution.

## 📋 Overview

This test suite project provides a ready-to-run test configuration for the **🎭 Playwright** automation framework (Python-based modern web testing).

The suite is pre-configured with:
- ✅ Proper project structure
- ✅ Dependencies configuration
- ✅ Test data fixtures
- ✅ Import scripts for automatic test loading
- ✅ Best practices and patterns

## 🚀 Quick Start

### Prerequisites

- **Python** (3.8 or higher)
- **Git** (optional)

### Import Tests

**Windows:**
```bash
import-tests.bat
```

**Linux/Mac:**
```bash
chmod +x import-tests.sh
./import-tests.sh
```

---

## 🎭 Playwright Suite

### Setup

```bash
cd playwright-suite
pip install -r requirements.txt
playwright install
```

### Import Tests

```bash
python scripts/import_tests.py
```

### Run Tests

```bash
# Run all tests
pytest tests/ -v

# Run with browser visible
pytest tests/ -v --headed

# Run with debug output
pytest tests/ -v -s
```

### Project Structure

```
playwright-suite/
├── tests/                       # Test files
│   └── test_generated.py
├── scripts/
│   └── import_tests.py          # Test import utility
├── conftest.py                  # Pytest fixtures
├── test_data.json              # Test data
├── pytest.ini                   # Pytest configuration
└── requirements.txt
```

## 🔄 Workflow

### 1. Generate Tests with TestCaptive Extensions

1. Use the **Chrome Extension** to capture user interactions
2. Use the **VS Code Extension** to generate test code
3. Generated tests are saved to `../Test-Code/` folder

### 2. Add Tests to Suite

> 💡 **See [IMPORT_METHODS.md](IMPORT_METHODS.md) for detailed comparison of both methods**

**Option A: Direct Copy (Recommended)**

Simply copy your generated test file to the appropriate location:

```bash
# Windows
copy Test-Code\Playwright.txt playwright-suite\tests\test_generated.py

# Linux/Mac
cp ../Test-Code/Playwright.txt playwright-suite/tests/test_generated.py
```

**Option B: Auto-Import (If cleanup needed)**

Use import scripts to automatically clean template artifacts and fix syntax:

```bash
cd playwright-suite && python scripts/import_tests.py
```

**When to use Auto-Import:**
- Code has `{{handlebars}}` template artifacts
- Duplicate variable declarations need fixing
- Want automatic syntax cleanup
- Need format conversion

### 3. Customize Test Data

Edit the `test_data.json` file to customize input values:

```json
{
  "input-first-name": "John",
  "input-last-name": "Doe",
  "input-email": "john.doe@example.com",
  "input-phone": "+1234567890",
  "select-country": "United States",
  "textarea-comments": "Your custom comment here"
}
```

### 4. Run Tests

Execute tests using the Playwright commands (see above).

## 🐛 Troubleshooting

### Playwright Issues

**Problem**: Browser not found
**Solution**: Run `playwright install` to download browsers

**Problem**: Import fails
**Solution**: Ensure `Test-Code/Playwright.txt` exists

# 🧪 TestCaptive Test Suite Project

A plug-and-play test suite project that automatically utilizes test code generated by TestCaptive's Chrome and VS Code extensions. Supports **Cypress**, **Playwright**, and **Selenium** frameworks.

## 📋 Overview

This test suite project provides ready-to-run test configurations for all three major automation frameworks:

- **🌲 Cypress Suite** - JavaScript/TypeScript E2E testing
- **🎭 Playwright Suite** - Python-based modern web testing
- **🔧 Selenium Suite** - Python-based traditional web testing

Each suite is pre-configured with:
- ✅ Proper project structure
- ✅ Dependencies configuration
- ✅ Test data fixtures
- ✅ Import scripts for automatic test loading
- ✅ Best practices and patterns

## 🚀 Quick Start

### Prerequisites

- **Node.js** (v16 or higher) - for Cypress
- **Python** (3.8 or higher) - for Playwright and Selenium
- **Git** (optional)

### Option 1: Import All Tests at Once

**Windows:**
```bash
import-tests.bat
```

**Linux/Mac:**
```bash
chmod +x import-tests.sh
./import-tests.sh
```

### Option 2: Import Tests for Specific Framework

See individual framework sections below.

## 🌲 Cypress Suite

### Setup

```bash
cd cypress-suite
npm install
```

### Import Tests

```bash
npm run import:tests
```

### Run Tests

```bash
# Run tests in headless mode
npm test

# Run tests with browser visible
npm run test:headed

# Open Cypress Test Runner (interactive)
npm run test:open
```

## 🔄 Workflow

### 1. Generate Tests with TestCaptive Extensions

1. Use the **Chrome Extension** to capture user interactions
2. Use the **VS Code Extension** to generate test code
3. Generated tests are saved to `../Test-Code/` folder

### 2. Add Tests to Suite

> 💡 **See [IMPORT_METHODS.md](IMPORT_METHODS.md) for detailed comparison of both methods**

**Option A: Direct Copy (Recommended)**

Simply copy your generated test file to the appropriate location:

```bash
# Windows
copy Test-Code\Cypress.txt cypress-suite\cypress\e2e\testcaptive-generated.cy.ts
copy Test-Code\Playwright.txt playwright-suite\tests\test_generated.py
copy Test-Code\Selenium.txt selenium-suite\tests\test_generated.py

# Linux/Mac
cp ../Test-Code/Cypress.txt cypress-suite/cypress/e2e/testcaptive-generated.cy.ts
cp ../Test-Code/Playwright.txt playwright-suite/tests/test_generated.py
cp ../Test-Code/Selenium.txt selenium-suite/tests/test_generated.py
```

**Option B: Auto-Import (If cleanup needed)**

Use import scripts to automatically clean template artifacts and fix syntax:

```bash
# Cypress
cd cypress-suite && npm run import:tests

# Playwright
cd playwright-suite && python scripts/import_tests.py

# Selenium
cd selenium-suite && python scripts/import_tests.py
```

**When to use Auto-Import:**
- Code has `{{handlebars}}` template artifacts
- Duplicate variable declarations need fixing
- Want automatic syntax cleanup
- Need format conversion

### 3. Customize Test Data

Edit the `test_data.json` file in your chosen suite to customize input values:

```json
{
  "input-first-name": "John",
  "input-last-name": "Doe",
  "input-email": "john.doe@example.com",
  "input-phone": "+1234567890",
  "select-country": "United States",
  "textarea-comments": "Your custom comment here"
}
```

### 4. Run Tests

Execute tests using the commands specific to your framework (see above).

## 🛠️ Customization

### Adding New Tests

1. Generate new tests using TestCaptive extensions
2. Re-run the import script
3. Tests will be automatically updated

### Modifying Test Configuration

Each suite has its own configuration file:

- **Cypress**: `cypress.config.ts`
- **Playwright**: `conftest.py` and `pytest.ini`
- **Selenium**: `conftest.py` and `pytest.ini`

### Extending Fixtures

Add custom fixtures in the respective `conftest.py` (Playwright/Selenium) or `commands.ts` (Cypress) files.

## 🐛 Troubleshooting

### Cypress Issues

**Problem**: Tests fail with "baseUrl" error
**Solution**: Update `cypress.config.ts` with the correct base URL

**Problem**: TypeScript errors
**Solution**: Run `npm install` to ensure all type definitions are installed

### Playwright Issues

**Problem**: Browser not found
**Solution**: Run `playwright install` to download browsers

**Problem**: Import fails
**Solution**: Ensure `Test-Code/Playwright.txt` exists

### Selenium Issues

**Problem**: ChromeDriver version mismatch
**Solution**: The `webdriver-manager` package automatically handles this

**Problem**: Tests run but browser doesn't appear
**Solution**: Remove `headless=True` from ChromeOptions in `conftest.py`

## 🔄 Typical Workflow

```
1. Capture User Flow
   └─> Chrome Extension

2. Generate Test Code
   └─> VS Code Extension
       └─> Saves to Test-Code/

3. Add Tests to Suite
   ├─> Option A: Direct copy (if code is clean)
   │   └─> Copy .txt to test folder
   └─> Option B: Auto-import (if cleanup needed)
       └─> Run import script
           └─> Cleans & converts

4. Run Tests
   └─> Execute via Playwright/Pytest
       └─> Get results

5. Iterate
   └─> Update test data
   └─> Add assertions
   └─> Scale tests
```

## 📞 Quick Commands Reference

### Import Tests
```bash
# Via script
import-tests.bat  # Windows
./import-tests.sh # Unix

# Individual
cd playwright-suite && python scripts/import_tests.py
```

### Run Tests
```bash
pytest tests/ -v           # Headless
pytest tests/ -v --headed  # With browser visible
```

### Install Dependencies
```bash
pip install -r requirements.txt       # Python deps
playwright install                    # Playwright browsers
```

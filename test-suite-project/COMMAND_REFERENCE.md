# ⚡ Quick Command Reference

One-page reference for both import methods across all frameworks.

---

## 🎯 Choose Your Method

### Method 1: 📁 Manual Copy (Fast & Simple)
Direct file copy - use when generated code is clean

### Method 2: 🤖 Auto-Import (Clean & Convert)
Run scripts - use when code needs cleanup

---

## 🌲 Cypress Suite

### Manual Copy
```bash
# Windows
cd test-suite-project\cypress-suite
copy ..\..\Test-Code\Cypress.txt cypress\e2e\testcaptive-generated.cy.ts

# Linux/Mac
cd test-suite-project/cypress-suite
cp ../../Test-Code/Cypress.txt cypress/e2e/testcaptive-generated.cy.ts
```

### Auto-Import
```bash
cd test-suite-project/cypress-suite
npm run import:tests
```

### Run Tests
```bash
npm test              # Headless
npm run test:headed   # With browser
npm run test:open     # Interactive
```

## 🎯 Decision Matrix

| Your Situation | Recommended Method |
|----------------|-------------------|
| Code is clean, no artifacts | 📁 Manual Copy |

## 💡 Pro Tips

### Windows Users
- Use `\` (backslash) in paths
- Use `copy` command
- Can use File Explorer to drag & drop instead

### Linux/Mac Users
- Use `/` (forward slash) in paths
- Use `cp` command
- Can use terminal autocomplete (Tab key)

### All Users
- **First time?** Use Auto-Import to be safe
- **Daily work?** Use Manual Copy for speed
- **Having errors?** Switch to Auto-Import
- **Batch updates?** Use the import-all scripts

## 🆘 Troubleshooting

### Manual Copy Issues

**File not found?**
```bash
# Check source exists
ls ../Test-Code/Cypress.txt

# Check you're in right directory
pwd
```

**Wrong file extension?**
```bash
# Make sure to rename when copying
# Cypress: .txt → .cy.ts
# Python: .txt → .py
```

### Auto-Import Issues

**Script not found?**
```bash
# Make sure you're in the suite folder
cd cypress-suite  # or playwright-suite or selenium-suite

# Check script exists
ls scripts/
```

**Import fails?**
```bash
# Verify source file exists
ls ../../Test-Code/

# Run with error output
npm run import:tests  # Cypress
python scripts/import_tests.py  # Python
```

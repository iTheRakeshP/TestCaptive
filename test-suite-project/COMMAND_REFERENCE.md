# ⚡ Quick Command Reference

One-page reference for both import methods for Playwright.

---

## 🎯 Choose Your Method

### Method 1: 📁 Manual Copy (Fast & Simple)
Direct file copy - use when generated code is clean

### Method 2: 🤖 Auto-Import (Clean & Convert)
Run scripts - use when code needs cleanup

---

## 🎭 Playwright Suite

### Manual Copy
```bash
# Windows
cd test-suite-project\playwright-suite
copy ..\..\Test-Code\Playwright.txt tests\test_generated.py

# Linux/Mac
cd test-suite-project/playwright-suite
cp ../../Test-Code/Playwright.txt tests/test_generated.py
```

### Auto-Import
```bash
cd test-suite-project/playwright-suite
python scripts/import_tests.py
```

### Run Tests
```bash
pytest tests/ -v              # Headless
pytest tests/ -v --headed     # With browser
pytest tests/ -v -s           # With output
```

---

## 🔄 Import via Script

### Auto-Import
```bash
# Windows
cd test-suite-project
import-tests.bat

# Linux/Mac
cd test-suite-project
./import-tests.sh
```

## 📊 File Paths Quick Reference

### Source Files (Generated by VS Code Extension)
```
Test-Code/
└── Playwright.txt   → Python test  
```

### Destination Files (Where tests should be)
```
test-suite-project/
└── playwright-suite/
    └── tests/
        └── test_generated.py
```

## 🎯 Decision Matrix

| Your Situation | Recommended Method |
|----------------|-------------------|
| Code is clean, no artifacts | 📁 Manual Copy |
| Code has `{{...}}` templates | 🤖 Auto-Import |
| Quick iteration/testing | 📁 Manual Copy |
| First time setup | 🤖 Auto-Import |
| CI/CD pipeline | 🤖 Auto-Import |
| Need to edit before import | 📁 Manual Copy |

## 💡 Pro Tips

### Windows Users
- Use `\` (backslash) in paths
- Use `copy` command
- Can use File Explorer to drag & drop instead

### Linux/Mac Users
- Use `/` (forward slash) in paths
- Use `cp` command
- Can use terminal autocomplete (Tab key)

### All Users
- **First time?** Use Auto-Import to be safe
- **Daily work?** Use Manual Copy for speed
- **Having errors?** Switch to Auto-Import
- **Batch updates?** Use the import-all scripts

## 🆘 Troubleshooting

### Manual Copy Issues

**File not found?**
```bash
# Check source exists
ls ../Test-Code/Playwright.txt

# Check you're in right directory
pwd
```

**Wrong file extension?**
```bash
# Make sure to rename when copying
# Playwright: .txt → .py
```

### Auto-Import Issues

**Script not found?**
```bash
# Make sure you're in the playwright-suite folder
cd playwright-suite

# Check script exists
ls scripts/
```

**Import fails?**
```bash
# Verify source file exists
ls ../../Test-Code/

# Run with error output
python scripts/import_tests.py
```
